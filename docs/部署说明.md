# GrowthLens Intern · 部署说明

## 一、运行环境

- JDK 21、Maven 3.6+、MySQL 8.0

- 端口: 后端 8080

## 二、准备数据库

1. 启动 MySQL(root / 123456)

2. 执行建库脚本: `mysql -uroot -p123456 < src/main/resources/sql/growthlens intern.sql`

   (自动建库 GrowthLens Intern + 建表 + 种子数据)

## 三、改配置

- 后端 `src/main/resources/application.yml`: 数据库密码、库名(默认已配好)

- 局域网访问: 将配置文件中 `localhost` 换成本机 IP(如 `jdbc:mysql://192.168.1.5:3306/GrowthLens%20Intern`)

## 四、启动

1. 后端: `mvn spring-boot:run`(或 `mvn package` 后 `java -jar target/growth-lens-intern-1.0.0.jar`)

2. 浏览器打开 http://localhost:8080/intern/login

## 五、常见问题

- 端口被占 → 换端口或关掉占用程序，修改 `application.yml` 中 `server.port`

- 连不上数据库 → 查密码/库名/MySQL 是否启动

- 列表空但接口有数据 → 检查前端取 `data.data` 不是 `data`

- 中文乱码 → JDBC url 已带 `characterEncoding=utf8`，库表用 utf8mb4

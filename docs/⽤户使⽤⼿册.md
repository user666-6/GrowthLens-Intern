二、普通用户
2.0 用户注册
  登录页点击【立即注册】→ 填用户名/密码/邮箱/昵称 → 点【注册】→ 提示"注册成功，请登录"
2.1 日报管理
   点左侧【日报周报管理】→ 【新增日报】→ 填今日完成/遇到问题/明日计划 → 点【提交】→ 提示"提交成功"。
2.2 AI润色日报
 新增日报页面 → 填完内容后点【AI润色】→ 系统自动优化内容 → 确认后【提交】。
2.3 编辑日报
  日报列表 → 找到目标日报点【编辑】→ 修改内容 → 点【保存】→ 提示"更新成功"。
2.4 删除日报
  日报列表 → 找到目标日报点【删除】→ 确认删除 → 提示"删除成功"。
2.5 导出日报
 日报列表 → 找到目标日报点【导出】→ 浏览器下载txt文件。






2.6 周报管理
  日报周报管理页面 → 切换到【周报】标签 → 【新增周报】→ 选年份/周数 → 填周总结/问题回顾/下周计划 → 【提交】。
2.7 AI生成周报
  新增周报页面 → 点【AI生成周报】→ 系统基于本周日报自动生成内容 → 编辑后【提交】。
2.8 编辑周报
 周报列表 → 找到目标周报点【编辑】→ 修改内容 → 点【保存】→ 提示"更新成功"。
2.9 删除周报
  周报列表 → 找到目标周报点【删除】→ 确认删除 → 提示"删除成功"。
2.10 导出周报
  周报列表 → 找到目标周报点【导出】→ 浏览器下载txt文件。
2.11 AI润色周报
 新增/编辑周报页面 → 填完内容后点【AI润色】→ 系统自动优化内容 → 确认后【提交】。






2.12 成长仪表盘
  点左侧【成长轨迹追踪】→ 查看仪表盘(技能分类/掌握程度/项目趋势/反馈统计)→ 切换标签查看详情。
2.13 新增技能
  成长轨迹页面 → 切换到【技能】标签 → 【新增技能】→ 填名称/类型/掌握程度/描述 → 【保存】→ 提示"添加成功"。


2.14 编辑技能
  技能列表 → 找到技能点【编辑】→ 修改信息 → 【保存】→ 提示"更新成功"。
2.15 删除技能
  技能列表 → 找到技能点【删除】→ 确认删除 → 提示"删除成功"。
2.16 更新技能掌握程度
  技能列表 → 找到技能 → 选择掌握程度(1-5星)→ 确认 → 提示"等级更新成功"。





2.17 新增项目
  成长轨迹页面 → 切换到【项目】标签 → 【新增项目】→ 填名称/角色/描述/职责/成果/技术栈 → 【保存】→ 提示"添加成功"。
2.18 编辑项目
  [截图] 项目列表 → 找到项目点【删除】→ 确认删除 → 提示"删除成功"。




2.20 STAR成果优化
  项目详情 → 点【STAR优化】→ AI根据项目信息生成专业成果描述 → 复制使用。
2.21 新增反馈
 成长轨迹页面 → 切换到【反馈】标签 → 【新增反馈】→ 填来源/类型/内容 → 【保存】→ 提示"添加成功"。
2.22 编辑反馈
  反馈列表 → 找到反馈点【编辑】→ 修改信息 → 【保存】→ 提示"更新成功"。








2.23 删除反馈
  反馈列表 → 找到反馈点【删除】→ 确认删除 → 提示"删除成功"。
2.24 创建目标
  点左侧【目标任务管理】→ 【新增目标】→ 填目标名称/描述/类型/优先级/起止日期 → 点【创建】→ 提示"目标创建成功"。









2.25 编辑目标
  目标列表 → 找到目标点【编辑】→ 修改信息 → 点【保存】→ 提示"目标更新成功"。
2.26 删除目标
 目标列表 → 找到目标点【删除】→ 确认删除 → 提示"目标删除成功"。
2.27 智能拆解目标
 新增目标页面 → 填目标名称/描述 → 点【智能拆解】→ AI生成SMART目标 → 点【创建并保存】。

2.28 新增任务
  目标列表 → 点目标名称进入详情 → 【新增任务】→ 填任务名称/描述/优先级/截止日期 → 【保存】→ 提示"任务添加成功"。
2.29 编辑任务
 目标详情 → 任务列表 → 找到任务点【编辑】→ 修改信息 → 点【保存】→ 提示"任务更新成功"。
2.30 删除任务
  目标详情 → 任务列表 → 找到任务点【删除】→ 确认删除 → 提示"任务删除成功"。
2.31 更新任务状态
 目标详情 → 任务列表 → 点任务状态按钮(未开始/进行中/已完成)→ 状态切换 → 提示"任务状态更新成功"。
2.32 智能拆解任务
  目标详情 → 点【智能拆解任务】→ AI生成子任务 → 点【保存】→ 提示"智能拆解并保存任务成功"。











2.33 智能复盘
  点左侧【智能复盘分析】→ 【生成复盘】→ 选类型(日/周/月复盘)→ 设置时间范围 → 【生成】→ 查看复盘报告。
2.34 查看复盘列表
 点左侧【智能复盘分析】→ 查看所有复盘记录列表 → 可按类型/时间筛选。
2.35 查看复盘详情
  复盘列表 → 找到记录点【详情】→ 查看完整复盘报告内容。
2.36 删除复盘记录
  复盘列表 → 找到记录点【删除】→ 确认删除 → 提示"删除成功"。
2.37 新增面试题
 
  点左侧【面经题库管理】→ 【新增题目】→ 填标题/内容/难度/掌握程度/来源 → 点【保存】→ 提示"添加成功"。





2.38 编辑面试题
  题库列表 → 找到题目点【编辑】→ 修改信息 → 点【保存】→ 提示"更新成功"。
2.39 删除面试题
  题库列表 → 找到题目点【删除】→ 确认删除 → 提示"删除成功"。
2.40 AI生成参考答案
  编辑题目页面 → 点【生成参考答案】→ AI生成专业回答 → 答案自动填充 → 点【保存】。

2.41 收藏题目
 题库列表 → 找到题目点【收藏】→ 提示"已收藏" → 题目加入收藏夹。
2.42 标记错题
 题库列表 → 找到题目点【标记错题】→ 提示"已标记为错题" → 题目加入错题本。
2.43 更新掌握程度
 题库列表/练习页面 → 找到题目 → 选择掌握程度(1-5星)→ 确认 → 提示"掌握程度已更新"。







2.44 新增分类
  题库页面 → 【分类管理】→ 【新增分类】→ 填名称/类型/备注 → 【保存】→ 提示"分类添加成功"。
2.45 编辑分类
  分类管理 → 找到分类点【编辑】→ 修改名称/排序/备注 → 【保存】→ 提示"分类更新成功"。
2.46 删除分类
  分类管理 → 找到分类点【删除】→ 确认删除 → 提示"分类删除成功"。






2.47 模拟练习
  题库页面 → 【模拟练习】→ 选模式(随机/错题/收藏/分类)→ 答题 → 查看参考答案 → 更新掌握程度。
2.48 职场智能助手
 点左侧【职场智能助手】→ 输入问题(如:"如何写好简历？")→ 【发送】→ AI返回回答 → 点【收藏】保存。











2.49 脚本生成
  智能助手页面 → 切换到【脚本生成】→ 选场景类型(请假申请)→ 填上下文 → 【生成】→ 复制使用。
2.50 学习计划生成
  智能助手页面 → 切换到【学习计划】→ 填技能名称/目标等级/时长 → 【生成】→ 获取个性化学习路径。











2.51 对话历史
  智能助手页面 → 切换到【历史记录】→ 查看所有对话记录 → 可按场景类型筛选。
2.52 收藏对话
  对话历史 → 找到记录点【收藏】→ 记录加入收藏 → 可筛选查看收藏记录。













2.53 删除对话记录
  对话历史 → 找到记录点【删除】→ 确认删除 → 提示删除成功。
2.54 个人信息
   点底部头像 → 进入个人中心 → 查看个人资料 → 【编辑资料】修改昵称/邮箱/手机号 → 【保存】。
2.55 修改密码
 个人中心 → 【修改密码】→ 输入原密码/新密码/确认密码 → 【确认】→ 提示"密码修改成功"。
三、管理员
3.1 用户管理
   登录admin → 左侧【用户管理】→ 查看用户列表 → 支持按用户名/昵称/状态筛选搜索。

3.2 新增用户
 提示"新增成功"。
3.3 编辑用户
  用户列表 → 找到用户点【编辑】→ 修改昵称/邮箱/手机号/状态 → 【保存】→ 提示"修改成功"。
3.4 删除用户
  用户列表 → 找到用户点【删除】→ 确认删除 → 提示"删除成功"。



3.5 禁用用户
 用户列表 → 找到用户点状态开关 → 状态切换为"禁用" → 禁用用户无法登录系统。
3.6 启用用户
  用户列表 → 找到已禁用用户点状态开关 → 状态切换为"启用" → 用户可正常登录。
